# Loop Practice

A collection of Python loop and introductory programming exercises in a Jupyter notebook. The notebook contains 40 numbered examples covering iteration, arithmetic, strings, lists, prime numbers, Fibonacci numbers, patterns, and list comprehensions. Some exercises request input interactively.

## Run the notebook

1. Install Python 3 and Jupyter Notebook (or use JupyterLab).
2. Open `06_oct_Loop assignemnet.ipynb` in Jupyter.
3. Run cells individually or use **Run All**. Enter values when prompted by interactive cells.

The examples use Python's standard library; no additional project dependencies are specified. The notebook is an exercise collection, so inspect individual cells if you encounter an error while running them.
